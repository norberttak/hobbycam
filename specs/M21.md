# M21 – Collapsible Layers / Operations pane (two vertical tabs)

Branch `feature/collapsible-panels`, from `main` (M13–M20 merged). Version 0.3.0.
Crates touched: `app` (`panels.rs`, `main.rs`, new `m21_verify.rs`, `shot.rs`), `hc-project` (`prefs.rs`).
**No project format change**, `PREFS_FORMAT_VERSION` stays 1, no new dependency, no new icon.
`specs/M21-mockup.html` is committed with this milestone (option B is the chosen one).

## User decisions (override anything below)
1. **Option B** of the mock-up: a narrow vertical strip between the tile sidebar and the canvas, with two independent
   vertical tabs, **Layers** (top) and **Operations** (below it). Each tab shows/hides its own section.
   Both open = stacked as today; one open = only that section, from the top of the pane; both closed = no pane, only
   the strip, the canvas gets the width.
2. The open/closed state is remembered **per computer** in `prefs.json` (two new bools on `hc_project::Prefs`,
   default open). Saved through `AppState::set_prefs` exactly like the M20 snap checkboxes: never dirty, never undo.
3. Properties keeps showing a selected operation while Operations is hidden (it is a separate pane; nothing changes).
4. Clicking an issue does **not** open a hidden tab. A dot on the Operations tab shows that an operation has issues.
5. No single-letter shortcuts.

## Scope
**In:** strip panel with two painted tabs (rotated text, a11y names, selected state, tooltip), `Prefs::layers_open`
/ `Prefs::ops_open`, `left()` showing only the open sections or nothing, issue dot, tests, docs, screenshots
regenerated + one new `panes-closed.png`.

**Out (explicitly):** a Properties strip (option D); a flyout (option C); slide animation / `show_collapsible`;
icons on the tabs; View menu items or any keyboard shortcut (Cmd+1/Cmd+2 included); auto-open on an issue click;
`CollapsingHeader`s inside the pane; any change to the Issues or Properties panes; prefs per project.

## Decisions
- **Strip** = its own panel `egui::Panel::left("pane_tabs")`, `.resizable(false)`, `.exact_size(STRIP_W)`,
  `.frame(egui::Frame::new().fill(ui.visuals().window_fill))` (no inner margin), default separator line kept (it is
  the strip's right border). `pub(crate) const STRIP_W: f32 = 22.0;` (the mock-up value). Called in `App::show`
  right after `panels::sidebar`, before `panels::left`. Always shown.
- **Tabs**: text only (no icons), `FontId::proportional(13.0)`, rotated −90° (reads bottom to top, as in the
  mock-up). Order top → bottom: Layers, Operations. Fallback, only if the rotated text renders wrong in the
  screenshot: draw the word's letters stacked top to bottom, one per line, centred (same rect sizes).
- **Look (B3-consistent, Visuals only, so dark mode follows):** fill = `widgets.active.bg_fill` while pressed, else
  `widgets.hovered.bg_fill` while hovered, else `selection.bg_fill` when open, else none (strip fill shows).
  Open tab also gets a 2 px accent bar (`hyperlink_color`) along its left edge and `strong_text_color()` text;
  closed tab text = `text_color()` (review: `weak_text_color()` was too pale on the strip fill; open vs closed is still told apart by fill, accent bar and strong text). Keyboard focus ring like the tiles (`hyperlink_color`, 2 px, inside).
  "Selected" means **open**.
- **Dot** on the Operations tab when any issue has `op.is_some()`: red (`error_fg_color`) when one of those is an
  Error, else orange (`warn_fg_color`) — the same colours as the per-op lines. Shown whether the tab is open or
  closed (it is the cheap overview; no rule to test twice). The Operations tab always reserves the dot's room, so its
  size never changes.
- **Pane**: drawn only when `layers_open || ops_open`; same id `"left"`, same `default_size(260.0)`, still
  user-resizable; its width is remembered by egui as today. Closing and reopening keeps the dragged width (egui
  memory is not cleared by not showing a panel).
- **New operation form** while Operations is hidden: `app.new_op` is untouched; reopening shows the form as it was.
- **No menu items, no shortcuts.** The strip is always on screen and focusable (Tab + Space/Enter click it). The
  interface.md sentence "It has the same commands as the menus" (about the sidebar) stays true because nothing is
  added to the menus. Adding View items later is two `ui.checkbox` lines.
- **A11y name** exactly `"Layers"` / `"Operations"` (`Role::Button`, selected = open); tooltip `"Hide Layers"` /
  `"Show Layers"`, `"Hide Operations"` / `"Show Operations"`. The pane headings are also named "Layers" /
  "Operations", so tests find the tab by its width (helper below).

pub(crate) const STRIP_W: f32 = 22.0;

/// The strip between the sidebar and the pane: two vertical tabs that show/hide Layers and Operations.
pub fn pane_tabs(app: &mut App, ui: &mut Ui);

/// Colour of the Operations tab dot: Some when an op has issues (error colour if any is an Error). Used by the painter.

`pane_tabs` body (sketch, keep this shape):
```rust
pub fn pane_tabs(app: &mut App, ui: &mut Ui) {
    let mut p = app.state.prefs;
    let dot = ops_dot(&app.state, ui.visuals());
    egui::Panel::left("pane_tabs")
        .resizable(false)
        .exact_size(STRIP_W)
        .frame(egui::Frame::new().fill(ui.visuals().window_fill))
        .show(ui, |ui| {
            ui.spacing_mut().item_spacing.y = 2.0;
            ui.add_space(4.0);
            if pane_tab(ui, "Layers", p.layers_open, None).clicked() {
                p.layers_open = !p.layers_open;
            }
            if pane_tab(ui, "Operations", p.ops_open, Some(dot)).clicked() {
                p.ops_open = !p.ops_open;
            }
        });
    app.state.set_prefs(p);
}
```
`fn pane_tab(ui, name: &str, open: bool, dot: Option<Option<Color32>>) -> egui::Response` (private;
`dot = Some(_)` means "reserve the dot room", inner `Some(c)` = paint it):
- `galley = ui.painter().layout_no_wrap(name.into(), FontId::proportional(13.0), text_color)`;
  `h = galley.size().x + 20.0 + if dot.is_some() { 10.0 } else { 0.0 }`;
  `(rect, r) = ui.allocate_exact_size(vec2(STRIP_W, h), Sense::click())`.
- Fill/bar/text colours as in Decisions; fill with `rect_filled(rect, 0.0, fill)`; bar =
  `Rect::from_min_size(rect.min, vec2(2.0, h))`.
- Text: the word's own rect is `t = Rect::from_min_size(rect.min, vec2(STRIP_W, galley.size().x + 20.0))`
  (the top part; the dot room is below it). With angle −π/2 a galley point `(x, y)` lands at `pos + (y, −x)`, so
  `pos = pos2(t.center().x - galley.size().y / 2.0, t.center().y + galley.size().x / 2.0)`;
  `ui.painter().add(epaint::TextShape::new(pos, galley, text_color).with_angle(-std::f32::consts::FRAC_PI_2))`.
- Dot: `circle_filled(pos2(rect.center().x, rect.bottom() - 8.0), 3.0, c)`.
- `r.widget_info(|| WidgetInfo::selected(Role::Button, true, open, name))`, then
  `r.on_hover_text(format!("{} {name}", if open { "Hide" } else { "Show" }))`.

`ops_dot`:
```rust
let mut it = s.issues.iter().filter(|i| i.op.is_some()).peekable();
it.peek()?;
Some(if it.any(|i| i.severity == hc_toolpath::Severity::Error) { v.error_fg_color } else { v.warn_fg_color })
```

`left()` becomes:
```rust
pub fn left(app: &mut App, ui: &mut Ui) {
    let (layers_open, ops_open) = (app.state.prefs.layers_open, app.state.prefs.ops_open);
    if !layers_open && !ops_open {
        return; // M21: only the tab strip
    }
    egui::Panel::left("left")
        .default_size(260.0)
        .show(ui, |ui| {
            // auto_shrink x off: else the panel shrinks to its content and loses the dragged width
            egui::ScrollArea::vertical().auto_shrink([false, true]).show(ui, |ui| {
                if layers_open {
                    layers(app, ui);
                }
                if layers_open && ops_open {
                    ui.separator();
                }
                if ops_open {
                    operations(app, ui);
                }
            });
        });
}
```

## Risks
- **Rotated text**: `with_angle` rotates around the galley's top-left; a wrong sign puts the word outside the strip
  (invisible, tests still pass). The screenshot check above is the guard; fallback is stacked letters.
- **Label clash**: tab and heading share "Layers"/"Operations"; any new test must use `tab()` or filter by width.
- **Canvas 22 px narrower** with both open (870 → 848 at 1280 px, Properties hidden). Accepted in the mock-up.
- **Dot meaning**: shown also while Operations is open (redundant with the per-op lines, harmless).
- Old prefs files with a future version are handled as in M20 (defaults, warning).
