# M19 – Measure tool

Branch `feature/measure-tool` (from `main`, version 0.3.0, M13–M18 merged). Crate touched: `app` only.
No project format change, nothing in G-code, no new dependency.

## User decisions (override anything below)
- Pick two points (snapped like the drawing tools: line end, contour corner, circle centre, …, or any raw point);
  a ruler (dimension line) shows the distance in the project units (mm / inch).
- The measurement is **temporary**: shown until a new measurement starts, `Esc`, or leaving the tool. Not saved in
  the project, never in G-code, never an undo step, never marks the project dirty.
- Distance on the ruler; **distance, ΔX, ΔY and angle** in the status bar and in the Properties pane.
- **No keyboard shortcut**: sidebar tile + Draw menu entry only (like Round corners).

## Scope
**In:** `CanvasTool::Measure`, click flow, live rubber-band ruler, fixed ruler, status bar text, Properties
read-out, sidebar tile (no row added), Draw menu entry, icon, canvas colour per theme, docs, one screenshot.

**Out (explicitly):** persistent / saved dimensions; dimensions in DXF or G-code; angle between two lines; area or
perimeter; chained (multi-segment) measuring; editable A/B fields; copy to clipboard; work-coordinate read-out of
A/B; perpendicular / nearest-point / tangent snaps (only the existing snap kinds); arrowheads; a keyboard shortcut.

## Existing code this builds on (read before coding)
- `AppState::pending: Option<Point>` holds the first click of Line/Rect/Circle; `set_tool` clears it, `escape()`
  drops it first, `history_moved` and `replace_project` clear it, `CanvasTool::hint(pending)` gives the status bar
  text. **Measure reuses `pending` for point A**, so all of that works unchanged.
- `canvas::input`: for every tool except Select and Fillet a primary click calls
  `s.snap_at(w, SNAP_PX / zoom)` and `canvas_click(snap.map_or(w, |sn| sn.p), snap.is_some())` — raw point when
  there is no snap. Measure uses this path unchanged (no new input code).
- `canvas::tool_overlay` draws the hover snap marker + label for every non-Fillet tool, then the dashed rubber band
  from `pending`. Measure keeps the marker part and adds the ruler.
- `panels::right` shows the pane whenever the tool is not Select / SetOrigin (Measure therefore shows it).
- `hc_project::fmt_len(mm, u)` = `"12.345 mm"` / `"0.4861 in"`; `to_display`.

## Decisions
1. **State:** A while picking B lives in `pending`; the fixed result in a new field `measure: Option<(Point, Point)>`.
   At most one of them is `Some`. The live pair (A, snapped cursor) is computed, not stored.
2. **Click flow:** click 1 = A (`pending = Some`, `measure = None`); moving shows the live ruler A → snapped cursor;
   click 2 = B (`measure = Some((A, B))`, `pending = None`); click 3 starts a new measurement (same as click 1).
3. **Esc:** pending A → dropped (tool stays Measure); else a fixed measurement → cleared (tool stays Measure); else
   leave to Select. `set_tool` (any tool, including Measure itself), `history_moved` (undo/redo) and
   `replace_project` (new/open) clear `measure`.
4. **Coordinates:** A and B in Properties are **drawing coordinates**, the same as the first "X … Y …" of the status
   bar and the X1/Y1 fields of the draw forms. ΔX/ΔY/distance/angle do not depend on the origin anyway.
5. **Signs and angle:** ΔX = B.x − A.x, ΔY = B.y − A.y (signed). Angle = direction A → B in degrees, CCW from +X,
   range **[0, 360)**, 2 decimals (AutoCAD/QCAD convention). A text that would read `360.00°` reads `0.00°`.
   Distance below `1e-9` mm: angle shown as `–`.
6. **Units / precision:** lengths through `fmt_len` (mm 3 decimals, inch 4 decimals, unit suffix on every value).
7. **Ruler look:** solid line A–B, perpendicular end ticks (6 px each side), **no arrowheads**; label = distance only,
   horizontal (always upright), on a filled rounded box, placed beside the line on its upper side, 8 px off the line.
   All sizes in screen pixels, so it works at any zoom. Colour: new `CanvasPalette::measure` (pink, see below).
8. **Sidebar:** Measure goes into the draw group after Set origin (row 4 becomes `Set origin | Measure`, both green);
   **Zoom to fit moves to the free cell of the File group** (`Export G-code… | Zoom to fit`). Row count stays 12.
   Reason: the 1280×800 fit report with Simulation open has 10 px slack; a new row needs 42 px
   (`m18v_sidebar_vertical_fit_report`: "slack after ring 10"). Tint is per action, so Zoom to fit stays green.

  ```rust
  /// the canvas. None outside the Measure tool.
  pub fn measure_live(&self) -> Option<(Point, Point)> {
      if self.tool != CanvasTool::Measure {
          return None;
      }
      if self.measure.is_some() {
          return self.measure;
      }
      let (a, c) = (self.pending?, self.cursor?);
      let b = self.snap_at(c, snap::SNAP_PX / self.view.zoom as f64).map_or(c, |sn| sn.p);
      Some((a, b))
  }
  ```

- New free functions (next to the other formatting helpers at module level, `pub`):

  ```rust
  /// Direction a → b in degrees CCW from +X, in [0, 360); None when |b − a| < 1e-9 mm.
  pub fn measure_angle(a: Point, b: Point) -> Option<f64> {
      let d = b - a;
      // rem_euclid of a tiny negative angle rounds to 360.0, hence the guard.
    (d.length() >= 1e-9).then(|| {
        let a = d.y.atan2(d.x).to_degrees().rem_euclid(360.0);
        if a >= 360.0 { 0.0 } else { a }
    })
  }

  /// "53.13°", "0.00°" for anything that rounds to 360.00, "–" for None.
  pub fn fmt_angle(a: Option<f64>) -> String {
      match a {
          None => "–".to_string(),
          Some(d) => match format!("{d:.2}°") {
              s if s == "360.00°" => "0.00°".to_string(),
              s => s,
          },
      }
  }

  /// Status bar text, e.g. "Distance 50.000 mm · ΔX 30.000 mm · ΔY 40.000 mm · Angle 53.13°".
  pub fn measure_summary(a: Point, b: Point, u: Units) -> String {
      let d = b - a;
      format!(
          "Distance {} · ΔX {} · ΔY {} · Angle {}",
          fmt_len(d.length(), u),
          fmt_len(d.x, u),
          fmt_len(d.y, u),
          fmt_angle(measure_angle(a, b))
      )
  }
  ```
  (`Point - Point`, `length()` and `distance()` exist on `hc_geom::Point`; `fmt_len` and `Units` are already
  imported in state.rs.)

  ```rust
  const RULER_TICK_PX: f32 = 6.0;
  const RULER_GAP_PX: f32 = 8.0;

  /// Centre of a label box of `size` beside the screen segment a–b: on the upper side (screen y up; the left side for
  /// a vertical line), its nearest edge RULER_GAP_PX from the line. Same result for a–b and b–a.
  fn ruler_label_center(a: Pos2, b: Pos2, size: Vec2) -> Pos2 {
      let d = b - a;
      let u = d / d.length();
      let mut n = Vec2::new(-u.y, u.x);
      if n.y > 0.0 || (n.y == 0.0 && n.x > 0.0) {
          n = -n;
      }
      let ext = RULER_GAP_PX + n.x.abs() * size.x / 2.0 + n.y.abs() * size.y / 2.0;
      a + d / 2.0 + n * ext
  }

  /// Dimension line a–b with perpendicular end ticks and the `text` label on a filled box (screen px, any zoom).
  /// Shorter than 1 px: only a small circle at a, no label.
  fn ruler(painter: &Painter, ui: &Ui, a: Pos2, b: Pos2, text: &str, col: Color32);
  ```
  `ruler` body: `st = Stroke::new(1.5, col)`; `len = (b - a).length()`; if `len < 1.0` →
  `painter.circle_stroke(a, 3.0, st)` and return. Else `u = (b - a) / len`, `n = Vec2::new(-u.y, u.x)`;
  `painter.line_segment([a, b], st)`; ticks `[a - n * RULER_TICK_PX, a + n * RULER_TICK_PX]` and the same at `b`.
  Label: `g = painter.layout_no_wrap(text.to_string(), egui::TextStyle::Body.resolve(ui.style()), col)`;
  `size = g.size() + Vec2::new(8.0, 4.0)`; `r = Rect::from_center_size(ruler_label_center(a, b, size), size)`;
  `painter.rect_filled(r, 3.0, ui.visuals().extreme_bg_color)` (the canvas colour of the theme);
  `painter.rect_stroke(r, 3.0, Stroke::new(1.0, col), egui::StrokeKind::Inside)`;
  `painter.galley(r.center() - g.size() / 2.0, g, col)`.

## Risks
- Moving **Zoom to fit** into the File group changes a tile position users know (tint stays green). Fallback if the
  user objects: Measure in that File cell instead, Zoom to fit back in place (only lists/tints in tests change).
- `measure_live` runs `snap_at` once more per frame for the overlay, status bar and Properties (3×); cheap compared
  with painting. If profiling ever shows it, cache the live pair per frame.
- Undo/redo clears a measurement (the geometry may have moved under it); documented by "temporary".
- The label box can cover geometry near the midpoint; it is opaque on purpose (readability beats seeing under it).
- `fmt_len` prints `-0.000 mm` for tiny negative deltas (e.g. −1e-7): accepted, matches the rest of the app.
