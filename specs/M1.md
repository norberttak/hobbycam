# M1 – Geometry core (`hc-geom`)

## Scope
**In:** 2D primitives (point, line, arc, circle, bulge polyline), bbox, length, affine transforms, chaining loose segments into contours, open/closed detection, signed area / orientation, point-in-contour, containment tree.
**Out:** offsets (M5, cavalier_contours), DXF (M2), text (M10), serialization logic beyond `derive` (M3), GUI, splines/ellipses (M2 flattens them to lines/arcs), boolean ops, self-intersection checks.

## Crate layout
`crates/hc-geom` (lib, `edition.workspace`, `license.workspace`). Dependencies: `serde = { version = "1", features = ["derive"] }` only. Every public type derives `Debug, Clone, PartialEq, serde::Serialize, serde::Deserialize` (`Copy` for `Point`, `Segment`, `Circle`, `BBox`, `Transform`).

| module | content |
|---|---|
| `lib.rs` | `pub use` of everything below; `pub const EPS: f64 = 1e-9;` `pub const DEFAULT_CHAIN_TOL: f64 = 0.01;` |
| `point.rs` | `Point` (also used as vector) |
| `segment.rs` | `Segment`, `Circle` |
| `bbox.rs` | `BBox` |
| `transform.rs` | `Transform` |
| `contour.rs` | `Contour`, `Orientation`, area, point-in-contour |
| `chain.rs` | `chain_segments` |
| `tree.rs` | `containment_tree`, `ContainmentNode` |

Units: f64 millimetres. Angles: radians, measured CCW from +X. Y axis points up (DXF convention).

## Types and API
```rust
pub struct Point { pub x: f64, pub y: f64 }
impl Point { new, add, sub, scale(f64), dot, cross(-> f64), length, distance(other), approx_eq(other, tol) }
// impl Add/Sub/Mul<f64> operators too.

pub enum Segment {
    Line { start: Point, end: Point },
    // sweep > 0 = CCW, < 0 = CW; |sweep| in (EPS, 2π]. |sweep| == 2π is a full circle.
    Arc  { center: Point, radius: f64, start_angle: f64, sweep: f64 },
}
```
Arc form = center/radius/start_angle/**signed sweep**: direction is the sign (no extra flag, mirror = negate sweep), and bbox/length/area are direct formulas; bulge is only an input format (`from_bulge`).
```rust
impl Segment {
    fn start(&self) -> Point;  fn end(&self) -> Point;
    fn length(&self) -> f64;            // arc: radius*|sweep|
    fn bbox(&self) -> BBox;             // arc: endpoints + every axis extreme (0, π/2, π, 3π/2) inside the sweep
    fn reversed(&self) -> Segment;      // arc: start_angle += sweep, sweep = -sweep
    fn transformed(&self, t: &Transform) -> Segment;
    fn arc_from_bulge(start: Point, end: Point, bulge: f64) -> Segment; // |bulge|<EPS -> Line; bulge>0 CCW; sweep = 4*atan(bulge)
}
pub struct Circle { pub center: Point, pub radius: f64 }
impl Circle { fn to_contour(&self) -> Contour } // one Arc, start_angle 0, sweep +2π, closed, CCW

pub struct BBox { pub min: Point, pub max: Point }
impl BBox { fn empty() -> BBox /*min=+inf,max=-inf*/; fn is_empty; fn include_point(&mut self, Point); fn union(&self, &BBox) -> BBox; fn contains_bbox(&self, &BBox) -> bool; fn width; fn height }

pub struct Transform { pub a: f64, pub b: f64, pub c: f64, pub d: f64, pub tx: f64, pub ty: f64 }
// x' = a*x + c*y + tx ; y' = b*x + d*y + ty
impl Transform {
    fn identity(); fn translate(dx, dy); fn rotate(angle, about: Point); fn scale(factor, about: Point);
    fn mirror_x(about_y: f64) /* flip across horizontal line y=about_y */; fn mirror_y(about_x: f64);
    fn then(&self, next: &Transform) -> Transform; // apply self, then next
    fn apply(&self, p: Point) -> Point;
    fn is_mirroring(&self) -> bool; // determinant < 0
}
```
Only uniform scale is supported (factor > 0; non-uniform would turn arcs into ellipses). Transforming an arc: transform center, `radius *= |scale|` (`sqrt(|det|)`), recompute start_angle from the transformed start point; if `is_mirroring()` negate sweep.

```rust
pub struct Contour { pub segments: Vec<Segment>, pub closed: bool }
pub enum Orientation { Ccw, Cw }
impl Contour {
    fn from_bulge_vertices(v: &[(Point, f64)], closed: bool) -> Contour; // (vertex, bulge to next); for M2 LWPOLYLINE
    fn start(&self) -> Point; fn end(&self) -> Point;
    fn length(&self) -> f64; fn bbox(&self) -> BBox;
    fn is_closed_within(&self, tol: f64) -> bool;   // end ≈ start
    fn signed_area(&self) -> f64;  // closed only (open -> 0.0). Lines: shoelace 0.5*cross(start,end);
                                   // arcs: 0.5*cross(start,end) + 0.5*r²*(sweep - sin(sweep))
    fn orientation(&self) -> Option<Orientation>; // None if open or |area| < EPS; area>0 -> Ccw
    fn reverse(&mut self);         // reverse order + reverse each segment
    fn set_orientation(&mut self, o: Orientation);
    fn contains_point(&self, p: Point) -> bool;   // closed only; even-odd ray cast +X, arcs handled exactly
                                                  // (intersect ray with circle, keep hits inside sweep); on-boundary unspecified
    fn transformed(&self, t: &Transform) -> Contour;
}
pub fn chain_segments(segments: &[Segment], tol: f64) -> Vec<Contour>;
pub struct ContainmentNode { pub contour: usize, pub parent: Option<usize>, pub depth: usize }
pub fn containment_tree(contours: &[Contour]) -> Vec<ContainmentNode>;
```

### Chaining algorithm (`chain_segments`)
Greedy, deterministic: take the first unused segment as a chain; repeatedly look among unused segments for one whose start or end lies within `tol` of the chain's **end** (reverse it if its end matched); when none, try extending the chain's **start** backwards the same way. Pick the nearest candidate (ties: lowest index). When nothing more attaches, `closed = chain.end ≈ chain.start (tol)`; when closed, snap the last segment's end coordinate exactly onto the first start only for `Line` (arcs keep their parameters). A full-circle arc is a closed contour on its own. Segments with length < EPS are dropped. Output order = order of each chain's first segment in the input. Junctions where >2 ends meet: greedy result is accepted (documented limitation). Complexity O(n²) is fine (shortcut: hobby drawings < few thousand segments; upgrade to a spatial grid if slow).

### Containment tree
Only closed contours participate; open contours get `parent: None, depth: 0` and are never parents. For contour i, parent = the closed contour j≠i with the **smallest |area|** such that `j.bbox().contains_bbox(i.bbox())`, `|area_j| > |area_i|` and `j.contains_point(i.start())`. depth = parent.depth + 1 (outermost 0). Result has one node per input contour, same index order. Assumes non-intersecting contours.

## Acceptance tests (inputs → expected, compare with 1e-9 unless noted)
1. Unit square lines (0,0)->(1,0)->(1,1)->(0,1)->(0,0): closed, `signed_area` = 1.0, orientation Ccw.
2. Same square traversed reversed: area = -1.0, Cw; after `set_orientation(Ccw)`: area 1.0.
3. The 4 square lines shuffled and two of them reversed, `chain_segments(.., 0.01)` → 1 contour, closed, 4 segments, |area| = 1.
4. Endpoints off by 0.005 → chained closed with tol 0.01; with tol 0.001 → not closed / multiple contours.
5. Open polyline (0,0)->(1,0)->(1,1) → 1 contour, `closed == false`, `orientation() == None`, area 0.
6. Two disjoint squares in mixed input order → 2 closed contours.
7. `Circle{(0,0), 1}.to_contour()`: closed, area = π, Ccw, length = 2π.
8. Arc center (0,0) r 2, start 0, sweep π/2: length = π; start (2,0), end (0,2).
9. Arc center (0,0) r 1, start π/4, sweep π/2 (crosses 90°): bbox max.y = 1.0, min.y = sin(π/4), x in [-cos π/4, cos π/4].
10. Half-disc: Line (-1,0)->(1,0) + Arc center (0,0) r1 start 0 sweep π → closed, area = π/2, Ccw.
11. Lower half-disc from bulge: Line (1,0)->(-1,0) + `arc_from_bulge((-1,0),(1,0), 1.0)` (bulge +1 = CCW semicircle, passes (0,-1)) → arc center (0,0), r 1, sweep π; contour area = π/2, Ccw. And `arc_from_bulge((0,0),(2,0),0.0)` is a Line.
12. `Transform::rotate(π/2, origin)` on Line (1,0)->(2,0) → (0,1)->(0,2) (tol 1e-9).
13. Mirror: `mirror_y(0)` on arc center (1,0) r1 start 0 sweep +π/2 → center (-1,0), sweep -π/2, start point (-2,0), end (-1,1).
14. Mirrored CCW unit square → orientation Cw, |area| unchanged.
15. `scale(2, origin)` on circle r1 → area 4π; `translate(5,-3)` on unit square → bbox min (5,-3), max (6,-2).
16. `then`: translate(1,0) then rotate(π/2, origin) applied to (0,0) → (0,1).
17. `contains_point` unit square: (0.5,0.5) true, (1.5,0.5) false; circle r1: (0.9,0) true, (0,1.1) false, (0.7,0.7) true; half-disc (test 10): (0,0.5) true, (0,-0.5) false.
18. Containment: square 10×10 at origin + circle center (5,5) r2 → square depth 0 parent None; circle depth 1 parent Some(0).
19. Nested 3 levels (squares 10, 6, 2 centered) given in reverse order → depths 0,1,2 correctly mapped by index; an extra open polyline → depth 0, parent None.
20. Two sibling circles inside one square → both parent = square, depth 1.
21. `reversed()` of an arc swaps start/end points, same length; `Contour::reverse` twice = original.
22. Zero-length line in chaining input is dropped.

Coder may add more; tester adds edge cases (degenerate arcs, tol boundaries, full-circle arc alone).

## Risks
- Arc angle wrap-around in bbox / point-in-contour: normalise angles with `rem_euclid(2π)`; test 9 and 17 cover it.
- Ray cast hitting a vertex exactly: use half-open rule (count crossing when one endpoint `y > p.y` and the other `<= p.y`); for arcs, treat hits at sweep endpoints with the same rule.
- Greedy chaining at T-junctions may pick a "wrong" partner; acceptable for M1, revisit with real DXFs in M2.

## Amendments after test round 1 (orchestrator, 2026-10-26)

A1. `Contour::contains_point`: endpoint coordinates used by the crossing rule must come from the exact
    `Segment::start()/end()` points (closing vertex identical for first start and last end), never
    recomputed from angles. A mirrored full circle must contain its centre.
A2. `chain_segments` must output truly connected contours: at every joint within tolerance,
    if the next segment is a Line, set its start = previous end; else if the previous is a Line, set its
    end = next start; else (arc→arc) insert a connector Line when the gap > EPS. Same for the closing joint.
    Area of a chained part must not depend on its position.
A3. `signed_area` computes the shoelace terms relative to the contour's first vertex (precision at 1e5 mm).
A4. `arc_from_bulge` with coincident start/end returns a (zero-length) Line; `Contour::from_bulge_vertices`
    skips consecutive duplicate vertices (|d| < EPS), so no NaN can appear.

## Architect review of the implementation (2026-10-26)
The spec is fully covered: acceptance tests 1–22 and amendments A1–A4 are implemented and tested, and the API matches the spec.

**Must-fix before commit**
R1. `chain_segments`: a chain of **one** segment counts as closed only if it is an `Arc` with `|sweep| > π`.
    Today a single Line (or a tiny arc) shorter than `tol` is "closed" right away. That (a) stops the chain from growing,
    so it never joins its neighbours, and (b) A2's closing joint then shrinks it to zero length (coder point e).
    Add a test: the input is a 0.005 mm line followed by a 1 mm line touching it. Expected: one open contour, and no degenerate closed contour.

**Rulings on the coder's points**
(a) Drop the named `Point::add`/`sub` methods and the `allow`, and keep the operator traits (this amends the spec's Point API). Acceptable either way, so it does not block the commit.
(b) `reverse` twice gives the start_angle back only within 1e-9: acceptable. Geometry is compared with a tolerance.
(c) Chaining stops once the chain closes: correct. Going on would trace a figure-8.
(d) `start()`/`end()` panic on an empty contour: acceptable. The panic is documented, and every internal caller guards against empty contours.
(e) Fixed by R1.

**Acceptable, noted (no action needed)**
- Identical duplicate contours (equal area) are not nested, so both get depth 0. This is tested. M2 or M5 may need to remove duplicates.
- A closed `from_bulge_vertices` call with a single vertex gives one zero-length Line. Its area is 0 and its orientation is None.
- A2 can make a Line shorter than `tol` collapse to zero length inside a chain. This is harmless for area and containment.
