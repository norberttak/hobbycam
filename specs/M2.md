# M2 – DXF import (`hc-dxf`)

## Scope
**In:** read ASCII DXF (R12 … AC1032/2018) from AutoCAD and QCAD, convert to `hc-geom` contours + points in **mm**, grouped by layer.
Entities: LINE, ARC, CIRCLE, LWPOLYLINE, POLYLINE (2D), SPLINE, ELLIPSE, POINT, INSERT (exploded).
**Out:** text import (M10), GUI (M4), writing DXF, 3D, HATCH boundaries, dimensions, layer on/off/frozen state (everything is imported), entity colour/linetype, binary DXF (the crate may read it, but it is untested and has no ignored-entity report).

## Library
`dxf = "0.6.2"` (latest on crates.io, MIT, pure Rust; deps image/chrono/encoding_rs etc. are all pure Rust MIT/Apache). Verified: it loads `drawings/Bracket.dxf` (AC1032, CRLF), gives `Version::R2018`, `header.default_drawing_units = Units::Inches`, and all LINE/CIRCLE/LWPOLYLINE (with bulges) correctly.
**Gap:** the crate silently **drops entity types it does not model** (HATCH is missing from `drawing.entities()`). So the ignored-entity report comes from a tiny raw scan (below), not from the crate.

## Crate layout
`crates/hc-dxf` (lib, workspace edition/license). Deps: `hc-geom` (path), `dxf = "0.6.2"`. Dev-deps: none extra (synthetic fixtures are built with `dxf` itself).

| module | content |
|---|---|
| `lib.rs` | public API, `import_dxf_bytes`, `import_dxf_file` |
| `entities.rs` | entity → segments/contours/points (incl. OCS mirror, INSERT explode) |

## Public API
```rust
pub struct ImportOptions { pub flatten_tol_mm: f64 /* 0.01 */, pub chain_tol_mm: f64 /* hc_geom::DEFAULT_CHAIN_TOL */ }
impl Default for ImportOptions

pub struct Layer {
    pub name: String,
    pub color: i16,             // ACI from the LAYER table, abs() (negative = layer off); 7 if not in the table
    pub contours: Vec<Contour>, // mm
    pub points: Vec<Point>,     // POINT entities, mm (drill candidates)
}
pub struct DxfImport {
    pub layers: Vec<Layer>,                // only layers that received geometry/points; first-appearance order in ENTITIES
    pub unit_scale: f64,                   // mm per drawing unit (25.4 for inches)
    pub ignored: BTreeMap<String, usize>,  // DXF type name -> count, e.g. {"DIMENSION": 6, "HATCH": 4}
    pub warnings: Vec<ImportWarning>,
}
pub enum ImportWarning {
    UnitsAssumedMm { insunits: i16 },            // $INSUNITS missing/0/unsupported code
    UnsupportedExtrusion { entity: String },     // normal not ±Z -> entity skipped
    PaperSpaceSkipped { count: usize },
    MissingBlock { name: String },
    InsertArrayFirstOnly { block: String },      // MINSERT: only the first copy imported
    SplineFitPointsOnly { layer: String },       // spline w/o control points -> polyline through fit points
    InsertNestingTooDeep { block: String },      // > 16 levels (cycle guard), that branch is skipped
}
pub enum DxfError { Io(std::io::Error), Parse(String) }   // impl Display + std::error::Error, From<dxf::DxfError>
impl DxfImport { pub fn bbox(&self) -> BBox; pub fn layer(&self, name: &str) -> Option<&Layer> }

pub fn import_dxf_bytes(bytes: &[u8], opts: &ImportOptions) -> Result<DxfImport, DxfError>;
pub fn import_dxf_file(path: &Path, opts: &ImportOptions) -> Result<DxfImport, DxfError>; // read + import_dxf_bytes
```
Derive `Debug, Clone, PartialEq` on the data types (no serde: the project file (M3) stores hc-geom geometry, not `DxfImport`). An empty but valid drawing returns `Ok` with no layers. Garbage input returns `Err(Parse)`, and it must never panic.

## Rules
**Units:** `$INSUNITS` → mm: 1 inch 25.4, 2 feet 304.8, 4 mm 1, 5 cm 10, 6 m 1000. Missing/0 (unitless)/anything else → 1.0 + `UnitsAssumedMm`. Output is always mm.

**Pipeline per entity:** build geometry in drawing units → apply the block/OCS transform → scale by `unit_scale` → collect into its layer. Flatten tolerance in drawing units = `flatten_tol_mm / unit_scale` (or flatten after scaling; the result is the same).
- An entity that is **closed by itself** (CIRCLE, closed LWPOLYLINE/POLYLINE, full ELLIPSE, closed SPLINE) becomes its own `Contour` and is **not** chained (so touching closed shapes, like the two rectangles in Bracket, stay separate).
- All other segments (LINE, ARC, open polylines/ellipse arcs/splines) go into a per-layer pool → `chain_segments(pool, chain_tol_mm)` after scaling to mm.
- Layer contour order: closed-entity contours in entity order, then the chained ones. Tests must not depend on that order beyond this rule.
- Zero-length lines and zero-radius arcs/circles are dropped silently. Z coordinates, elevation, thickness and width are ignored.

**Entities:**
- LINE, POINT, SPLINE, ELLIPSE (center/axis): WCS coordinates, used as-is.
- ARC/CIRCLE: `Segment::Arc` with sweep = (end−start) normalised to (0, 2π], CCW; CIRCLE = `Circle::to_contour()`.
- LWPOLYLINE / POLYLINE: `Contour::from_bulge_vertices` (closed flag = bit 1). POLYLINE with the 3D (8), polygon-mesh (16) or polyface (64) flag → `ignored["POLYLINE (3D/mesh)"] += 1`. Vertices flagged spline-frame control point (16) are skipped.
- ELLIPSE: `minor = ratio · (−nz·major.y, nz·major.x)` (this handles a −Z normal). If |ratio−1| < 1e-9 → exact `Arc`. Otherwise uniform parameter sampling, n = max(4, ceil(|Δt| / (2·acos(1 − tol/|major|)))) line segments. If end < start, add 2π. Δt ≈ 2π → closed.
- SPLINE: rational B-spline (de Boor; empty weights = all 1) from control points + knots. Sample each non-empty knot span by recursive bisection until the distance from the midpoint to the chord is ≤ tol (max depth 10). Output: lines only. Closed when flag bit 1 is set or the endpoints coincide within tol. No control points but fit points → polyline through the fit points + `SplineFitPointsOnly` (shortcut: fit-point interpolation is not implemented; upgrade if real files need it).
- **OCS / extrusion:** ARC, CIRCLE, LWPOLYLINE, POLYLINE and the INSERT location are in OCS. With normal (0,0,+1), use them as-is. With (0,0,−1) (common in AutoCAD after mirroring), apply `Transform::mirror_y(0.0)` (x → −x) to the built geometry. Any other normal (|nx| or |ny| > 1e-9) → skip the entity + `UnsupportedExtrusion`. LINE/POINT/SPLINE are WCS, so they need no mirror.
- INSERT: T = translate(−block.base) → scale(sx, sy) → rotate(rotation°) → translate(location) → (mirror X if the insert normal is −Z) → parent T. Build the affine `Transform` directly (its fields are public); this handles negative scale (mirror) through `is_mirroring`. **Non-uniform** (|sx| ≠ |sy|, rel 1e-9): lines/points are transformed exactly; arcs/circles are first flattened to lines (`flatten_tol`) and then transformed. A block entity on layer `"0"` takes the INSERT's layer. Recursive, max depth 16. MINSERT (row/col count > 1) → first copy + warning. ATTRIB is ignored. DIMENSION blocks (`*D…`) are never exploded.
- Paper-space entities (`is_in_paper_space`) are skipped + one `PaperSpaceSkipped{count}`.

**Ignored report (`scan.rs`):** scan the raw bytes as (code, value) line pairs (trim, CRLF ok). Inside `SECTION/ENTITIES` count every `0/<TYPE>`. `ignored` = counts of every type **not** in {LINE, ARC, CIRCLE, LWPOLYLINE, POLYLINE, SPLINE, ELLIPSE, POINT, INSERT, VERTEX, SEQEND, ATTRIB}, plus the crate-side `"POLYLINE (3D/mesh)"` entries. Ignored types are never an error. Not ASCII → empty map.

## Fixtures (project convention)
All fixture files live at the **repo root** in `tests/fixtures/<kind>/` (DXF: `tests/fixtures/dxf/`, later `tests/fixtures/ngc/`). Tests reach them with `concat!(env!("CARGO_MANIFEST_DIR"), "/../../tests/fixtures/dxf/…")`.
- Copy `drawings/Bracket.dxf` → `tests/fixtures/dxf/autocad2018_bracket_inch.dxf`. The QCAD file comes later from the user.
- Synthetic fixtures are **built in test code** with `dxf::Drawing` (add entity → `save` to `Vec<u8>` → `import_dxf_bytes`), one per entity type. The HATCH/unknown-type test uses a short hand-written ASCII DXF string literal (the crate cannot write HATCH).

## Acceptance tests (mm, tol 1e-6 unless noted)
**Bracket (`autocad2018_bracket_inch.dxf`, default options):**
1. `unit_scale` = 25.4, `warnings` empty, no points anywhere.
2. Layers in order: `Outline, Center, Hidden, Title` (exactly 4; Dimensions/Notes/Hatch/0/Defpoints are absent). Colors: Outline 7, Center 1, Hidden 2, Title 7.
3. `ignored` == {DIMENSION: 6, HATCH: 4, MTEXT: 1, TEXT: 6}.
4. Outline: 12 contours = 10 closed + 2 open. Circles (closed contours with 1 full-sweep arc): 6, radii 7.9375 ×4, 38.1, 22.225. Outline bbox (25.4, 25.4)–(330.2, 152.4).
5. The outer rounded rectangle: 8 segments (4 lines + 4 arcs r 12.7), |area| = 25667.947 (tol 1e-3), length 638.596 (tol 1e-3). Slot (bulge = 1 ends): |area| 597.201 (tol 1e-3), bbox x 96.52–157.48, y 38.1–48.26.
6. `containment_tree` over the Outline closed contours: depth 0 → 3 (outer, 2 side-view rectangles), depth 1 → 6 (4 holes, Ø76.2 circle, slot), depth 2 → 1 (Ø44.45 inside Ø76.2).
7. Center: 11 open contours (center marks stay separate lines). Hidden: 1 closed circle r 28.575. Title: 2 closed + 3 open.
8. Whole-drawing `bbox()` = (−12.7, −12.7)–(457.2, 190.5). Total circles over all layers = 7.

**Synthetic:**

11. Four LINEs of a 10×10 square in shuffled order on layer "A" → 1 closed contour, |area| 100.

14. POLYLINE 2D closed square → 1 closed contour; a 3D POLYLINE → `ignored["POLYLINE (3D/mesh)"] == 1`.
15. Full ELLIPSE center (0,0), major (10,0), ratio 0.5 → closed, lines only, every vertex satisfies (x/10)²+(y/5)² = 1 (tol 1e-9), max chord deviation ≤ 0.01, |area| within 0.1 % of 50π. Ratio 1 → a single exact `Arc`. A half ellipse (0→π) → open, endpoints (10,0) and (−10,0).
16. SPLINE degree 1 through (0,0),(10,0),(10,10) → polyline with those vertices (collinear samples allowed). A degree-2 clamped spline with control points (0,0),(5,10),(10,0) → start (0,0), end (10,0), midpoint (5,5) (tol 1e-6), every sample within 0.01 of the true curve. A fit-points-only spline → `SplineFitPointsOnly`.
17. POINT (5,5) on layer "Drill" → `layer("Drill").points == [(5,5)]`, no contours.
18. INSERT of block "B" (base (1,1), a LINE (1,1)-(2,1) on layer "0" + a CIRCLE r1 at (1,1) on layer "X") at (10,0), rotation 90°, scale 2 on layer "L" → layer "L": line (10,0)-(10,2); layer "X": circle center (10,0) r 2. Rotation 0, scale (−1, 1) → line (10,0)-(9,0), circle center (10,0) r 1 with negative sweep. Rotation 0, scale (2, 1) → line exactly (10,0)-(12,0); the circle becomes lines only (an ellipse), closed, bbox x [8,12], y [−1,1] (tol 0.01).

20. A hand-written DXF with HATCH + 2 TEXT + 1 LINE → `ignored == {HATCH:1, TEXT:2}`, 1 line imported, no error.

## Risks
- The crate drops unknown entity types silently: covered by the raw scan (tests 3 and 20). If a future file has a supported type that the crate fails on, the counts will differ. The tester should compare the scan count with the imported count for supported types on Bracket.
- Greedy chaining at T-junctions (Title layer lines end on other lines' midpoints): they stay open contours. This is expected, not a bug.
- Center marks on the "Center" layer are imported as geometry. The user filters by layer in the GUI, and no auto-ignore by layer name is done.
- Splines/ellipses become many line segments. That is fine for hobby use. Arc fitting is a later option if G-code size matters.

## Amendments after implementation (orchestrator, 2026-10-26)

A1. Test 15: the inscribed polygon from the chord-deviation formula (n=71 for r=10, tol 0.01) loses
    ~0.13% area, so the bound is relaxed to "|area| within 0.2% of 50π". The ignored duplicate test is removed.
A2. Input that contains no `0`/`SECTION` group pair (e.g. 0-byte or whitespace-only file) returns
    `Err(Parse)` before the dxf crate is called. An empty but well-formed drawing still returns Ok.

## Architect review of the implementation (2026-10-26)
State: `cargo test -p hc-dxf` → 49 passed (4 unit, 23 acceptance, 22 edge cases), clippy `-D warnings` clean, fmt clean.
Spec tests 1–22 and A1 are covered, and the API matches the spec exactly.

**Must-fix before commit**
R1. INSERT cycle guard is exponential. A block that inserts itself k times recurses k^16 times
    (k=2 gives 65k copies and 65k warnings; k=3 is effectively a hang). Track the chain of block names
    being expanded (a `Vec<&str>` passed down); when a name is already in it, push one
    `InsertNestingTooDeep` and skip. Keep the depth-16 limit as well.
    Test: block "S" containing 3 INSERTs of "S" → returns quickly, 1 warning (or ≤ 3), no geometry duplication explosion.
R2. Dropped splines must not vanish silently (point e): a missing contour means a part is not milled.
    Count them in `ignored["SPLINE (invalid)"]`, the same way as `"POLYLINE (3D/mesh)"`, so no new warning variant is needed.
    This covers both an inconsistent definition and fewer than 2 fit points with no control points. Add one test.

**Acceptable (no change)**
- Untested: ELLIPSE with normal (0,0,−1), both the ratio-1 arc and a flattened partial ellipse. The formula is correct
  by reading. The tester should add one test: the test-15 half ellipse (major (10,0), ratio 0.5, 0→π) with normal −Z
  runs from (10,0) to (−10,0) through (0,−5), the lower half instead of the upper.
- `Vec<Geo>` is always one element, so a plain `Geo` would do. This is minor, so it does not block the commit.
- `scan.rs` uses `slice::as_chunks` (Rust ≥ 1.88). This is fine on stable CI; note it if an MSRV is ever set.
- Ignored types inside blocks (e.g. TEXT in an INSERTed block) are not counted. The spec scans ENTITIES only.

**Rulings on the coder's points**
(a) Only top-level paper-space entities skipped: accepted. Block contents follow their INSERT.
(b) ELLIPSE with a tilted normal → skipped + `UnsupportedExtrusion`: accepted (it is the general rule).
(c) Flatten tol / largest scale of the full transform: accepted. This bounds the chord error in mm for every transform.
(d) Non-uniform = "the composed transform is not conformal" (unequal column lengths or shear): accepted.
    It is more correct than comparing sx/sy, because nested rotate + non-uniform scale produces shear.
(e) Inconsistent spline dropped silently: rejected → R2.
(f) `catch_unwind` around `Drawing::load`: accepted. It does not help if a profile ever sets `panic = "abort"`.
    Keep the default unwind for release builds.
(g) Missing `$INSUNITS` = 0 (unitless → mm + warning): accepted.
