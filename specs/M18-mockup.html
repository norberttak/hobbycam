HobbyCAM M18 - pick a look

Three options for the new, more colourful UI. Each one is an HTML mock of the main window (same menus, sidebar buttons and groups as app/src/panels.rs sidebar_groups), with a light and a dark variant. Hover a sidebar button for its name. State shown: Select tool active, Show toolpaths on, one shape selected (so Delete/Rotate/Flip are enabled), Redo disabled.

The icons here come from a pinned CDN (@phosphor-icons/web@2.1.2) for the mock-up only; the app would embed the chosen .ttf with include_bytes! as it does today, so it stays self-contained. Text font in the mock is the browser's; the app keeps egui's default font.
