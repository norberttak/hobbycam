# M14 – Settings window

Branch `feature/settings-window`. App crate only; no project format change, no new dependency.

## Scope
**In:** one floating `Settings` window with three sections (Units, Machine, Stock) holding exactly the fields of today's
`units_menu` / `machine_menu` / `stock_menu`; opened from **File → Settings…** (`Cmd/Ctrl+,`) and one sidebar button;
the top-level **Settings** menu and the three sidebar popups (Units, Machine, Stock) go away; **Tool library…** moves to
the File menu. Docs and screenshots.

**Out:** any new preference or a General/App section (nothing real to put there yet), OK/Cancel/Apply, a list/tab layout,
moving the tool library into the window, persisting the window position, field validation beyond today's.

## Decisions
| # | topic | decision | why |
|---|---|---|---|
| D1 | Menu | Remove the top-level `Settings` menu. File menu, after `Export G-code…` and a separator: `Settings…` (shortcut `Cmd/Ctrl+,`), `Tool library…`, then separator, `Quit` | "Settings → Settings…" would be silly; File is where Windows apps keep it, egui has no macOS app menu |
| D2 | Shortcut | `SC_SETTINGS = KeyboardShortcut::new(Modifiers::COMMAND, egui::Key::Comma)` handled in `panels::shortcuts` | macOS convention; egui 0.37 has `Key::Comma`, `format_shortcut` shows `⌘,` / `Ctrl+,` |
| D3 | Sidebar | Last group becomes `[Tool library…, Settings…]` (one row). Icon: the gear (today `icons::MACHINE`, renamed `icons::SETTINGS`); `icons::UNITS`, `icons::STOCK` deleted | one button per window, like Tool library; sidebar gets one row shorter |
| D4 | Layout | One window, sections stacked top to bottom: heading `Units`, today's units radios; separator; heading `Machine`, the machine grid; separator; heading `Stock`, the stock content. No tabs, no scroll area | ~520 px tall, fits 1280×800; a later preference is one more section |
| D5 | Apply | Live, exactly like the menus today: each frame clones, edits, calls `set_units` / `set_machine` / `set_stock` | those set `dirty` only on a real change; undo is snapshot based (`commit_undo(idle)` in `App::show`), so every edit is already one undo step per drag/typing; OK/Cancel would fight undo |
| D6 | Close | Title-bar X (`Window::open`), `Esc` when no text field has focus, and **Pick on drawing** (it sets the Set origin tool and closes the window so the canvas is free) | `Esc` is consumed before the canvas sees it, so it does not also cancel the tool / clear the selection |
| D7 | Window | `egui::Window::new("Settings").open(&mut open).collapsible(false).resizable(false).default_pos(egui::pos2(400.0, 60.0))` | auto size; `default_pos` keeps it off the sidebar and left panel |

## Changes (exact)

`app/src/main.rs`
- `pub struct App`: add field `pub settings_open: bool` (doc: `/// The Settings window is open.`), `false` in `App::new`.
- `App::show`: call `panels::settings_window(self, &ctx);` right after `tool_dialog::show(self, &ctx);` (before `commit_undo`),
  then `self.kb_focus = ctx.egui_wants_keyboard_input();`. Field `pub kb_focus: bool` (`false` in `App::new`): egui drops
  focus on Esc before `shortcuts()` runs, so the Esc check needs last frame's focus (as built; replaces
  `!ctx.egui_wants_keyboard_input()` below).

`app/src/panels.rs`
- `item()`: set `widget_info` with the plain `text` so the accessible name has no shortcut suffix (as built; tests find
  `Settings…` by exact label).
- Add `const SC_SETTINGS: KeyboardShortcut = KeyboardShortcut::new(Modifiers::COMMAND, egui::Key::Comma);`
- `shortcuts()`: add
  ```rust
  if ctx.input_mut(|i| i.consume_shortcut(&SC_SETTINGS)) {
      app.settings_open = true;
  }
  // before the canvas reads Esc: closing the window must not also cancel the tool
  if app.settings_open
      && !app.kb_focus
      && ctx.input_mut(|i| i.consume_key(Modifiers::NONE, egui::Key::Escape))
  {
      app.settings_open = false;
  }
  ```
- `menu()`: delete the whole `ui.menu_button("Settings", …)` block. In the File menu, after `Export G-code…` insert
  `ui.separator();`, `if item(ui, "Settings…", Some(&SC_SETTINGS)) { app.settings_open = true; }`,
  `if item(ui, "Tool library…", None) { app.tool_dialog.open = true; }`; the existing separator + `Quit` follow.
- New:
  ```rust
  /// Units, Machine and Stock in one window; edits apply live (undo and dirty as for any edit).
  pub fn settings_window(app: &mut App, ctx: &egui::Context) {
      let mut open = app.settings_open;
      if !open { return; }
      egui::Window::new("Settings")
          .open(&mut open)
          .collapsible(false)
          .resizable(false)
          .default_pos(egui::pos2(400.0, 60.0))
          .show(ctx, |ui| {
              ui.heading("Units");
              units_section(app, ui);
              ui.separator();
              ui.heading("Machine");
              machine_section(app, ui);
              ui.separator();
              ui.heading("Stock");
              stock_section(app, ui);
          });
      // Pick on drawing may have closed it during show
      app.settings_open &= open;
  }
  ```
- Rename `units_menu` → `units_section`, `machine_menu` → `machine_section`, `stock_menu` → `stock_section` (bodies
  unchanged, incl. the `Grid` ids and labels) except: in `stock_section` replace `ui.close();` with `app.settings_open = false;`.
- Sidebar: delete `SideAct::Menu(...)` and `fn side_menu`; add `SideAct::Settings`. In `sidebar_buttons` drop the
  `if let SideAct::Menu` branch (always `side_button`), drop `| Some(SideAct::Menu(_))` from the match, add
  `Some(SideAct::Settings) => app.settings_open = true,`. Last group in `sidebar_groups`:
  ```rust
  vec![
      entry(icons::TOOLS, "Tool library…", None, SideAct::Tools),
      entry(icons::SETTINGS, "Settings…", sc(&SC_SETTINGS), SideAct::Settings),
  ],
  ```
- Line ~896: `"No tools: add one in Settings > Tool library…"` → `"No tools: add one in File > Tool library…"`.

`app/src/icons.rs`: `MACHINE` → `pub const SETTINGS: &str = "\u{e270}"; // gear`; delete `UNITS`, `STOCK`;
`ALL: [&str; 22]` without them, `MACHINE` → `SETTINGS`.

## Risks
- `Esc` is consumed while the window is open, so an egui menu popup opened on top of it needs a click outside to close.
  Acceptable.
- `Window` auto-size with `resizable(false)`: if a later preference makes it taller than 800 px, add a `ScrollArea` then.
- Label collisions: `X`, `Y`, `Width`, `Height` also appear in Properties forms; tests 2/5 use `fresh()` (nothing selected,
  Select tool, so the Properties pane is hidden).
