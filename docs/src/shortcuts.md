# Shortcuts

On macOS use **Cmd**, on Windows and Linux **Ctrl**.

## Keyboard

| Action | Key |
|---|---|
| New | `Cmd/Ctrl+N` |
| Open project… | `Cmd/Ctrl+O` |
| Save | `Cmd/Ctrl+S` |
| Save as… | `Cmd/Ctrl+Shift+S` |
| Import DXF… | `Cmd/Ctrl+I` |
| Export G-code… | `Cmd/Ctrl+E` |
| Undo | `Cmd/Ctrl+Z` |
| Redo | `Cmd/Ctrl+Shift+Z` or `Ctrl+Y` |

These keys work with the mouse over the canvas and no text field active:

| Action | Key |
|---|---|
| Select (also cancels the active tool or the first click) | `Esc` |
| Line | `L` |
| Rectangle | `R` |
| Circle | `C` |
| Text | `T` |
| Set origin | `O` |
| Zoom to fit | `F` |
| Delete selection (or the selected tab) | `Del` or Backspace |

`Esc` in Select mode clears the selection.

## Mouse

| Action | Input |
|---|---|
| Zoom at the cursor | mouse wheel, trackpad pinch, or `Cmd/Ctrl` + scroll |
| Pan | trackpad two-finger scroll, middle-button drag, or `Space` + drag |
| Select | click |
| Add to / remove from selection | `Shift` + click |
| Select inside a box | drag left to right |
| Select touching a box | drag right to left |
| Add a tab | double-click on the contour |
| Move a tab | drag its marker |
