# G-code and LinuxCNC

## Files

HobbyCAM writes **one file per tool segment**: a run of enabled operations in a row that use the same tool,
in list order.

- One segment: `<name>.ngc`
- Several: `<name>_<k>_T<n>.ngc`, for example `bracket_1_T1.ngc`, `bracket_2_T2.ngc`. *k* is padded with zeros
  to the number of digits of the total, so with 10 or more files you get `_01_T3`, `_02_T1`, …
- The order T1 → T2 → T1 gives **three** files, because the tool changes twice.

*name* is what you type in the export dialog. If a file of that name exists, it is replaced and the old one is kept
as `….ngc.bak`.

## Inside a file

Each file starts with comments for you:

```text
(<file name> - file k of n)
(Generated by HobbyCAM, LinuxCNC post)
(Units: mm. Z0 = top of stock. XY0 = <origin>)
(Tool: T<n> <tool name>)
(Op: <operation name>)            one line per operation
(Before running: load T<n> <tool name> and set Z0 on top of stock)
```

The units say `inch` in an inch project; the origin is "drawing origin", "stock bottom left", "stock center"
or "drawing point X… Y…".

Then:

- the setup line `G17 G21 G40 G49 G80 G90 G91.1 G94 G98` (`G20` instead of `G21` in inch), then `G64 P0.01`
  (inch: `G64 P0.0004`) and `G0 Z<safe Z>`;
- for each spindle speed `S<rpm> M3` followed by `G4 P2`, a 2 second wait for the spindle to spin up
  (there is no at-speed signal);
- arcs as `G2` / `G3` with `I` / `J` relative to the start point;
- holes as `G81`, or `G83 … R<clearance Z> Q<peck>` with peck drilling;
- at the end `G0 Z<tool change Z>`, `M5`, `M2`.

Numbers have 3 decimals in mm and 4 in inch, without trailing zeros.
Not written: `T`, `M6`, `M0`, `G43`, coolant, line numbers, `%`.

## Running a job

- **XY0** is the origin you picked in HobbyCAM; the header says which one. Set G54 X and Y there once.
  The files do not select a coordinate system themselves, so **G54 must be active** (it is after LinuxCNC starts,
  unless you switched to another one).
- **Z0** is the top of the stock. Touch it off **for every file**, because each tool sticks out of the collet by a
  different amount. You do not need a tool table or `G43`: touch off with **no tool length offset active**
  (each file starts with `G49`, which cancels it).

For each file:

1. Load the tool named in the header.
2. Touch off Z on the stock top with G54 active: `G10 L20 P1 Z0`, or the **Touch Off** button with 0.
   With paper or a feeler gauge, a probe or a touch plate under the tool, enter its thickness instead of 0
   (for a 0.1 mm feeler: `G10 L20 P1 Z0.1`). Leave X and Y alone.
3. Run the file. At the end the machine goes to tool change Z with the spindle off.
4. Change the tool and go on with the next file.

## Before the first run

- [ ] The units in the header match your machine setup.
- [ ] G54 X and Y are at the origin you picked.
- [ ] Tool change Z is reachable: on thick stock, Z0 plus tool change Z must stay below the Z limit.
- [ ] Clamps are outside all moves, including the rapids (the dashed lines on the canvas), or lower than Safe Z.
- [ ] A spoilboard is under through-cuts.
- [ ] Spindle direction and RPM range are right.

**Air cut**: touch off Z higher than the deepest Depth in the file plus at least 5 mm (for example Depth + 10 mm),
or raise G54 Z by that much, and run the file once in the air. Tool change Z plus that extra height must still fit
inside the machine's Z travel. Then touch off on the real stock top. Watch the first plunge with a hand on the E-stop.
